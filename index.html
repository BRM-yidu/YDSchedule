移动端安装指引

Android 直接下载 APK 安装；iOS 通过「添加到主屏幕」使用，两种方式体验一致

1

Android：下载 APK

点击上方「下载 Android APK」，下载后打开安装。首次安装需在系统提示中允许「安装未知应用」。

2

iOS / 其他：打开 Web 版

在手机浏览器（Safari / Chrome / Edge）访问 brm-yidu.github.io/YDSchedule/ydschedule-web/

3

添加到主屏幕

Android：浏览器菜单 →「添加到主屏幕」；iOS：分享按钮 →「添加到主屏幕」，即可全屏使用。

常见问题

你可能想知道的

桌面版如何更新到新版本？

打开应用 → 设置 → 程序信息 →「检查更新」。应用会自动从更新源获取最新版本，发现新版本后点击下载即可。也可直接到本页重新下载最新安装包覆盖安装，数据不会丢失。

换电脑 / 换浏览器后数据还在吗？

数据保存在本机（桌面版在本机存储，Web 版在浏览器本地）。如需迁移，请在「数据管理」中导出备份文件，再到新设备导入。

Web 版和桌面版数据互通吗？

目前各端数据独立保存在本地。可通过「数据导出 / 导入」功能在端与端之间迁移数据。

移动端没有 App Store 版本吗？

Android 用户可直接下载 APK 安装包安装（无需应用商店审核）；iOS 用户通过「添加到主屏幕」以 PWA 方式使用，体验与原生 App 一致。后续视需求可发布应用商店版本。
