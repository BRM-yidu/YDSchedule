# 极简日程表 YDSchedule

四端可用的极简日程表应用：Web / PWA / Windows / macOS。

## 特性

- 极简界面，专注日程管理，高自由度定制
- 自然语言语义解析：输入「一小时后去晾衣服」「明天早上八点吃药」自动设置日程
- 今日 / 周 / 月三种视图
- 本地数据存储，无需注册账号，数据不出本机
- 插件系统：可扩展标签、样式、导航、视图
- 可选云端 AI 语义解析（需自备 API 密钥，默认本地解析）

## 使用

直接打开 `ydschedule-web/index.html` 即可使用，或部署到任意静态服务器 / GitHub Pages。

## 桌面端构建

```bash
cd desktop
npm install
npm run dist
```
